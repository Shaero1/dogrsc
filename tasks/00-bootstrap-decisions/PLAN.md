## Альтернативы

- **Монорепо (`frontend/`, `backend/` в `dogrsc`):** отвергнута, потому что выбраны отдельные репо — независимый CI/CD, изоляция admin, проще права доступа; цена — синхронизация OpenAPI между репо.
- **Один язык в MVP + i18n-каркас:** отвергнута, потому что спека (раздел 27) и явное требование заказчика — три языка с первого релиза; откладывание удвоит работу по контенту и URL.
- **Отдельный репо `dogrsc-contracts`:** отвергнута на старте, потому что добавляет третью точку синхронизации без текущей нужды; OpenAPI в backend достаточно для двух клиентов.
- **Query-параметр `?lang=` вместо path `/en/`:** отвергнута, потому что хуже для SEO (раздел 28) и canonical URL.
