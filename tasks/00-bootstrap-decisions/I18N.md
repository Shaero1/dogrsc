# Стратегия i18n — MVP

Дата: 2026-07-31  
Спека: PDF, раздел 27

## Локали

| Код | Язык | MVP |
|-----|------|-----|
| `en` | English | да, default fallback |
| `th` | ไทย | да |
| `ru` | Русский | да |

## URL (публичный frontend)

Префикс локали в path:

```text
/en/dogs/luna-looking-for-home
/th/dogs/...
/ru/dogs/...
```

- Переключатель языка в footer (раздел 33 спеки) сохраняет текущий path, меняя только префикс.
- Canonical URL и hreflang — при реализации SEO (раздел 28).
- Default redirect: `/` → `/en/` (или по `Accept-Language` / cookie — уточнить в frontend-scaffold).

## Frontend (`dogrsc-frontend`)

- **Библиотека:** `next-intl` (App Router).
- **Файлы переводов:** `messages/en.json`, `messages/th.json`, `messages/ru.json` — UI-строки (меню, кнопки, ошибки форм, labels).
- **Контент из API:** запрос с `Accept-Language: th` или query; backend отдаёт поле на нужной локали с fallback `en`.

## Admin (`dogrsc-admin`)

- **UI:** только **en** в MVP (staff).
- **Редактирование контента:** формы с вкладками или полями En / Th / Ru для:
  - статических страниц (главная, about, FAQ);
  - описаний собак (`description`, `rescue_story`);
  - SEO-полей (title, meta description) — по сущности.

## Backend

### Хранение переводимого контента

**Гибрид (рекомендация):**

1. **Dogs** — колонки `description_en`, `description_th`, `description_ru` (и аналоги для `rescue_story`, seo) ИЛИ JSONB `descriptions: { en, th, ru }` — выбор при миграциях schema-задачи.
2. **ContentTranslations** — для страниц CMS, FAQ, баннеров: `entity_type`, `entity_id`, `locale`, `field`, `value`.

### API

- Публичные GET: заголовок `Accept-Language: th` → тексты на th, иначе fallback en.
- User-generated (found/lost reports): **один язык автора**, автоперевод не делаем; автоперевод только как черновик для CMS (раздел 27) — не в MVP forms.

### Users

- Поле `preferred_language` (раздел 20.1) — для ЛК, этап 2.

## Что переводим в MVP

| Область | en/th/ru |
|---------|----------|
| UI публичного сайта | ✅ |
| Статический контент (about, footer, FAQ) | ✅ |
| Описания собак (из админки) | ✅ |
| SEO title/description | ✅ |
| Email-шаблоны (минимум) | ✅ — подтверждение контакта, модерация |
| Объявления found/lost от пользователей | ❌ |
| Admin UI | ❌ (только en) |

## Seed-контент

Для приёмки MVP нужны **не пустые** строки на всех трёх языках хотя бы для:

- главное меню;
- hero на главной;
- 1–2 профиля собак;
- footer.

Допускаются короткие заглушки на th/ru до текстов от заказчика.

## Отвергнуто

- Один язык + «подключим i18n позже» — отвергнуто (требование MVP).
- Query `?lang=th` без path — отвергнуто (SEO).
