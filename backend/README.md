# backend (dogrsc-backend)

NestJS REST API for Doge Rescue — часть монорепо `dogrsc`.

## Setup

```powershell
cd c:\dogrsc
npm install
cd backend
copy .env.example .env
```

## Development

Из корня монорепо:

```powershell
npm run dev:backend
```

Или из `backend/`:

```powershell
npm run start:dev
```

- API base: `http://localhost:4000/api/v1`
- Health: `http://localhost:4000/api/v1/health` — includes `database: ok` when Postgres is up

## Database (Prisma)

**Prerequisite:** infra Postgres running:

```powershell
cd c:\dogrsc\infra
docker compose -f docker-compose.dev.yml up -d
```

Configure `DATABASE_URL` in `backend/.env` (see `.env.example`).

```powershell
cd c:\dogrsc\backend
npm run db:migrate      # apply migrations (dev)
npm run db:generate     # regenerate Prisma Client
npm run db:migrate:deploy  # production/staging apply
npm run db:seed            # upsert dev admin user (requires ADMIN_* env)
```

MVP schema: `prisma/schema.prisma` — users, dogs, reports, donations, crypto_addresses, media, content_translations, audit_logs.

## Auth

JWT access tokens for admin (`ADMIN` / `STAFF` roles). Env vars in `.env.example`:

- `JWT_SECRET` — **change in production**
- `JWT_EXPIRES_IN` — default `8h`
- `ADMIN_EMAIL`, `ADMIN_PASSWORD` — used by seed

```powershell
npm run db:seed
```

Endpoints:

- `POST /api/v1/auth/login` — `{ email, password }` → `{ accessToken, user }`
- `GET /api/v1/auth/me` — Bearer token, `@Roles(ADMIN, STAFF)`

Default dev credentials (after seed): `admin@dogerescue.org` / `changeme-dev-only`

## Media (admin API)

Upload images to MinIO/S3; metadata in `media` table. Requires Bearer token (`ADMIN` or `STAFF`).

Env: `MEDIA_MAX_BYTES` (default 5 MB), `MEDIA_PRESIGNED_TTL_SECONDS` (default 900), plus `S3_*`.

| Method | Path | Description |
|--------|------|-------------|
| POST | `/api/v1/admin/media` | multipart field `file` — jpeg/png/webp, max 5 MB |
| GET | `/api/v1/admin/media/:id` | metadata + presigned GET URL |
| DELETE | `/api/v1/admin/media/:id` | soft delete (`deletedAt`); S3 object kept until background cleanup |

Delete rules: **ADMIN** — any media; **STAFF** — own upload or media linked to an entity (`entityType` + `entityId`).

Admin UI upload — task `10-dogs`.

## Dogs

Admin CRUD under `/api/v1/admin/dogs` (`ADMIN` / `STAFF`). Archive: `POST .../archive` (**ADMIN only**). Sets `status=ARCHIVED`, `isPublished=false`.

Public read: `GET /api/v1/dogs`, `GET /api/v1/dogs/:slug` — only `isPublished=true` and `status` in `AVAILABLE`, `IN_CARE`. Locale: `Accept-Language` header (en/th/ru, fallback en).

Slug: autogenerated from `descriptions.en.name` on create; manual override supported.

Seed demo dogs: `npm run db:seed`.

## Reports (found / lost)

Public submit (no auth):

| Method | Path | Description |
|--------|------|-------------|
| POST | `/api/v1/found-reports` | Create found report → `PENDING` |
| POST | `/api/v1/lost-reports` | Create lost report → `PENDING` |
| POST | `/api/v1/found-reports/:id/media` | Optional photo (multipart `file`) |
| POST | `/api/v1/lost-reports/:id/media` | Optional photo |

Public media upload allowed for **15 min** after report creation (`REPORT_MEDIA_UPLOAD_WINDOW_MINUTES`). Uses system user (`SYSTEM_USER_EMAIL`, seeded).

Admin moderation (`ADMIN` / `STAFF`):

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/admin/found-reports` | List (optional `?status=PENDING`) |
| GET | `/api/v1/admin/found-reports/:id` | Detail + media |
| PATCH | `/api/v1/admin/found-reports/:id` | `{ status: APPROVED \| REJECTED }` — only from `PENDING` |
| GET/PATCH | `/api/v1/admin/lost-reports/...` | Same for lost |

Seed: pending demo reports + system user via `npm run db:seed`.

## Map (public markers)

Read-only markers for the public map page. Only **APPROVED** reports with non-null coordinates. No reporter contact fields.

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/map/markers` | List markers; query `type=found\|lost\|all` (default `all`) |

Response item: `id`, `type`, `description`, `latitude`, `longitude`, `createdAt`, optional `thumbnailUrl`.

Seed includes 2 APPROVED map demos (Bangkok area) via `npm run db:seed`.

## Donate (crypto addresses + donation records)

Static crypto donation addresses for the public donate page. Each currency has at most one **active + displayed** address on `/donate`. Admin can store inactive backup addresses per currency. Currency codes are free-form (e.g. `BTC`, `SOL`).

### Public

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/donate/crypto-addresses` | Active addresses only (`@Public()`) |
| POST | `/api/v1/donate/donations` | Report donation `{ amount, donorName, donorEmail, paymentMethod: BANK\|CRYPTO, currency? }` → `PENDING` |

### Admin crypto addresses

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/admin/crypto-addresses` | All addresses (ADMIN/STAFF) |
| POST | `/api/v1/admin/crypto-addresses` | `{ currency, address }` → active by default |
| PATCH | `/api/v1/admin/crypto-addresses/:id` | `{ address?, isActive? }` |

### Admin donation records

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/admin/donations` | List; query `status`, `page`, `limit` |
| POST | `/api/v1/admin/donations` | Manual create `{ amount, donorName?, donorEmail?, paymentMethod?, status?: PENDING\|CONFIRMED }` |
| PATCH | `/api/v1/admin/donations/:id` | `{ status: CONFIRMED\|FAILED }` — only from `PENDING` |

Seed: demo BTC/ETH/USDT/DOGE addresses + one `CONFIRMED` bank donation (1000 THB) + one `PENDING` crypto donation (500 THB) via `npm run db:seed`.

## Dashboard (admin stats)

Aggregate counts for the admin dashboard (`ADMIN` / `STAFF`):

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/admin/dashboard/stats` | `{ dogsUnderCare, reportsPending, donationsThisMonth, dogsAvailable }` |

- `dogsUnderCare` — `status = IN_CARE`
- `reportsPending` — found + lost `PENDING`
- `donationsThisMonth` — sum `CONFIRMED` donations in current UTC month (THB)
- `dogsAvailable` — `status = AVAILABLE` (includes unpublished)

## Users (admin panel accounts)

Manage ADMIN/STAFF accounts (`ADMIN` only). `system@dogerescue.org` is excluded; public `USER` role not listed.

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/admin/users` | List; query `role`, `page`, `limit` |
| POST | `/api/v1/admin/users` | `{ email, password, role: ADMIN\|STAFF }` |
| PATCH | `/api/v1/admin/users/:id` | `{ role?, password? }` — cannot demote last admin |

Seed: `admin@` + `staff@` via `npm run db:seed` (`STAFF_EMAIL` / `STAFF_PASSWORD` in `.env`).

## CMS content (ContentTranslation)

Static page copy for about, contact, stories, and donate bank details. Public read with locale fallback to `en`; admin bulk upsert (`ADMIN` only).

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/content/pages/:entityId` | Public; query `locale` (en\|th\|ru) |
| GET | `/api/v1/admin/content/pages` | Page manifest (id, label, fields) |
| GET | `/api/v1/admin/content/pages/:entityId` | All stored translations |
| PUT | `/api/v1/admin/content/pages/:entityId` | `{ items: [{ locale, field, value }] }` |

Entity IDs: `home`, `faq`, `about`, `contact`, `stories`, `donate-bank`. Seed fills rows from default copy via `npm run db:seed`.
